# HashMapLib

## Tiny
This was the goal: 2 files, easy to integrate.

## Strengths
- Fast
- Small
- Easy to read and expand
- Easy to integrate
- Easy to use

## Weaknesses
- No cryptographic hashing
- HashMap can only grow, not shrink

## Use
Drag n' drop the C implementation and header files then:
```c
#include "hashmaplib.h"
```
